# CoinGlass 行情观察扩展

## 安装

1. 在 Edge 打开 `edge://extensions`（Chrome 打开 `chrome://extensions`）。
2. 打开「开发人员模式」，点击「加载解压缩的扩展」。
3. 选择 `D:\Git\Project\Other\Coin\extension` 文件夹。
4. 将扩展固定到工具栏，点击图标查看行情。

更新文件后，在扩展管理页点击该扩展的「重新加载」，使新版本生效。

扩展默认显示 DOGE、BTC、ETH、SOL、BNB 的价格和 Binance BTC/USDT 清算地图。清算地图使用全部价格档位，按 10x、25x、50x、100x 杠杆倍数分色绘制柱状图，并显示多单、空单累计清算曲线和现价虚线。浏览器运行时每 10 秒尝试刷新两个接口；点击 ↻ 可立即刷新。工具栏图标采用白底黑字，把 DOGE 价格的小数点后五位分成两行，例如 `0.07734` 显示为上行 `0.07`、下行 `734`；悬停可查看单行完整价格。价格是接口请求时的快照。

Chrome 的闹钟最短周期为 30 秒。扩展用后台计时器尝试维持 10 秒刷新，并用 30 秒闹钟在后台进程休眠后恢复；浏览器休眠、系统睡眠或网站限流时，实际间隔可能超过 10 秒。

## 设置

弹窗底部的「设置」直接显示关注币种和清算地图交易对的 DOGE、BTC、ETH、SOL、BNB 快捷按钮。关注币种可多选，至少保留一个；清算地图一次选择一个 Binance/USDT 交易对。点击按钮后立即保存并刷新。币种和交易对不再提供自定义输入；此前保存的其他关注币种仍会显示成按钮，可点击取消。`obe` 默认空白，扩展会从 CoinGlass 页面发往其 API 的请求头自动读取并保存。点击「从 CoinGlass 页面获取 obe」可重新加载页面并重试。旧版手动保存的 `obe` 不再使用。

扩展只请求 `capi.coinglass.com`，并读取 `www.coinglass.com` 页面发往该 API 的 `obe` 请求头。需要获取请求头或页面协助发起请求时，它会使用现有 CoinGlass 标签页，或创建一个未激活、固定的标签页。页面没有发出带 `obe` 的请求时，设置区会显示未获取，可点击重试。

清算地图展示的是估算清算强度，不能当成已经发生的爆仓金额。网页内部接口的参数、权限或加密方式变更后，扩展可能需要更新。
